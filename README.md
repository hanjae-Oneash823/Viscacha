# Viscacha

Viscacha is a computational pipeline for investigating how alternative splicing 
and protein isoform diversity affect drug efficacy and off-target toxicity in 
Alzheimer's disease (AD).

Starting from cell-type-resolved, pseudo-bulk transcript counts derived from 
long-read scRNA-seq data, the pipeline identifies disease-relevant isoforms, 
predicts their 3D structures, and compares small-molecule binding affinity across 
isoforms via molecular docking — with the goal of explaining efficacy failures 
and unexpected side effects at the isoform level.
