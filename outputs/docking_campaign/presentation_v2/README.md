# Docking presentation visuals — version 2

These files supersede the earlier presentation graphics.

## Recommended slide order

1. `final/01_FYN_validated_result.png` — primary result: nine independent redocking runs recover the known FYN–saracatinib pose.
2. `final/02_FYN_pocket_overlay.png` — molecular close-up: crystal saracatinib and the best Vina pose occupy the same pocket.
3. `final/03_KIT_canonical_baseline.png` — secondary result and scope boundary: reproducible canonical KIT scores, but no KIT-223 comparison because residue 715 is unresolved in PDB 1T46.

Each slide is supplied as a 3840 × 2160 PNG and a vector-friendly PDF. The molecular views are ray-traced from the actual protein structures and docking poses; they are not illustrative or AI-generated protein art.

## Color key

- Teal: crystallographic saracatinib / validated result
- Orange: best docked saracatinib pose
- Purple: docked masitinib
- Red: validation threshold or structural limitation

## Presentation wording

Use “pose-recovery validation” for FYN. Avoid claiming experimental binding affinity, cellular efficacy, or an isoform-dependent KIT effect from these preliminary docking results.
